# Al-Qutūfud Daaniyah Online Qur’anic Academy

Updated website package.

## Included
- Public homepage with realistic local images
- Apply Now followed by Explore Our Programmes
- Free Trial Class section with WhatsApp and email
- Programmes: Tahfizul Qur’an, Qur’an & Tajweed, Islamic Studies, Arabic Studies, Qur’an Recitation
- Concise Why Al-Qutūfud Daaniyah section with Learn More WhatsApp message
- Separate student login page
- Student dashboard with welcome notification and classes
- Supabase authentication files

## Upload
Upload the contents of `final_site` to the root of the GitHub Pages repository. Image files are also duplicated at the root intentionally so the website images work even when a phone/browser does not preserve the assets folder during upload. The `assets` folder is retained as well.
