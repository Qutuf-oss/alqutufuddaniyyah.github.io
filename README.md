# Al-Qutūfud Daaniyah Online Qur'anic Academy

This version follows the requested green/cream/gold reference style with realistic Qur'an-learning visuals.

## Pages
- `index.html` — public academy homepage.
- `student-login.html` — separate student login/create-account page.
- `student-dashboard.html` — private student dashboard after login.

## Student flow
Home → Student Login → Login/Create Account → Student Dashboard → Classes → Join Zoom → Logout.

The public homepage no longer contains the student login form. The existing `logo.png` is preserved.

The realistic teacher/student visual is an AI-generated website visual and is not presented as a photograph of an actual academy teacher.
