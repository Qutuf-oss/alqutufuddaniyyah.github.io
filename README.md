# Al-Qutūfud Daaniyah Online Qur'anic Academy

This package is the rebuilt public website and separate student portal.

## Included
- Public homepage with realistic local Qur'an-learning imagery.
- Stronger academy introduction and detailed About section.
- Qur'an Recitation, Qur'an & Tajweed, Islamic Studies and Tahfizul Qur'an programmes.
- Free Trial Class section.
- WhatsApp and email contact buttons.
- Separate Student Login / Create Account page.
- Separate Student Dashboard with welcome notification, classes and Zoom links.
- Local `assets/` folder so images work on GitHub Pages without relying on external image URLs.
- Existing academy logo preserved.

## GitHub Pages structure
Keep `index.html`, `student-login.html`, `student-dashboard.html`, JavaScript, CSS, configuration and `logo.png` in the repository root. Keep all images inside the `assets/` folder.

## Supabase
The browser uses the Supabase publishable key in `supabase-config.js`. Never put a Supabase secret/service-role key in this website.

## Important
The hero/learning visuals are website artwork and should not be presented as photographs of actual academy staff unless the academy has permission and authentic photographs for that purpose.
